
# CampusConnect

A Django-based University Management Web Application with a dedicated Web Security Assessment Lab.

## Project Overview

CampusConnect aims to provide a centralized platform for university-related academic and administrative activities.

The project is also a practical learning environment for Django development, web application security, vulnerability assessment, and security remediation.

## Planned Features

- Student, Teacher, and Admin roles
- User authentication and profile management
- Course and enrollment management
- University notice board
- Student complaint management
- Document upload and download
- Admin dashboard
- Search functionality
- REST API integration

## Technology Stack

- Python
- Django
- HTML, CSS, JavaScript
- Bootstrap
- SQLite (initial development)
- Git and GitHub
- GitHub Actions (planned)

## Learning Objectives

- Learn Django through practical development
- Understand Git and collaborative workflows
- Implement automated testing and CI
- Identify and fix common web vulnerabilities
- Prepare professional security assessment reports

## Security Notice

This project is intended for educational purposes. Security testing will be conducted only in an isolated local lab or other explicitly authorized environments.

Intentionally vulnerable test cases must never be deployed to a public production environment.
